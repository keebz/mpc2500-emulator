**Experimental software. Read the notice shown at every start-up and the disclaimer in the README. Testing a firmware in the emulator gives no guarantee that it works on real hardware, and installing firmware on a real unit can damage it beyond repair. Provided as is, with no warranty.**

### New: a virtual unit that installs firmware like the real hardware
- The emulator now keeps the flash chip (boot block, installed OS, settings and **internal memory**) in a file, `unit.flash`, in your *MPC2500 Emulator* folder. What you install stays installed.
- The chooser has **Power on**, **Flash OS**, **Developer direct load** and **Reset unit**. Start with the stock Akai OS (**Flash OS**), then **Power on**.
- The firmware's own installers now decide what is accepted. The stock OS refuses the large JJOS XL / OS3 / Light images ("File too big"). Install **JJOS JV 3.13** first, then install XL, OS3 or Light from JV 3.13's **Load** page, exactly as on the unit. This chain is covered by an automated test and checked byte for byte.
- The old "load anything directly" behaviour is still available as **Developer direct load**, clearly labelled as a shortcut that skips the installer.

### Fixed
- **Flash emulation bug:** a flash write whose data ended in `F0` was mistaken for the "reset" command, so the OS updaters stopped after about 1.3 KB and never finished. Firmware updates (and any other flash writes of such data) now complete correctly.
- **macOS:** the chooser is always shown (v0.1.1 skipped it when only one firmware was installed); a card built in the chooser is used on the first launch.
- Short taps on panel buttons now register.

### Also new
- **Cheat Sheet** overlay (`Ctrl/Cmd+/` or the button on the top bezel) listing every key binding, and a **Firmware / Card** button on the bezel (same as `Ctrl+O`).
- The chooser and the start-up notice use a normal, readable font and layout. The notice is in plain sentence case.
- The version is shown in the window title and the chooser. The app folder and uninstall steps are documented (README and Quick Start).
- MAIN VOLUME now changes the output level (REC GAIN is still not connected).

### Notes
- No firmware is included; supply your own.
- The macOS builds are ad-hoc signed, not notarised: right-click, **Open** the first time.
- Not covered: the boot-block recovery updater (`MPC2500.SOS`) from the chooser, and power loss in the middle of an install.
