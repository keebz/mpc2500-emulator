**Experimental software. Read the notice shown at every start-up and the disclaimer in the README. Testing a firmware in the emulator gives no guarantee that it works on real hardware, and installing firmware on a real unit can damage it beyond repair. Provided as is, with no warranty.**

### Fixed
- **Panel LEDs never lit in the downloadable apps (Linux and macOS).** The file that maps the firmware's LED bits to the panel keys (`led_map.txt`) was never part of the repository, so the packaged apps shipped without it. Buttons such as FULL LEVEL (stays lit) and MODE (blinks) only showed the brief click highlight. The file is now tracked, generated into the skin, and the build scripts refuse to package without it.
- **Memory now defaults to the stock 16 MB** (it was 128 MB). The 128 MB expansion is a choice: **RAM** button in the chooser (or `M`), or `--ram 128`. The memory card is a separate file and has nothing to do with the unit's memory; the 128 MB figure was only the default size of a new card image.

### Changed
- **The Quick Start Guide (PDF) is included in every download** (next to the app in the macOS `.zip` / `.dmg` and in the Linux folder) and opens from the new **Quick Start** button in the chooser.
- The documentation now describes installing **any Extra Large (XL) OS, one that is larger than the stock OS area**: the flash map, exactly how such an install overwrites the settings sector and then the start of the internal memory, sector by sector, and the recovery route reported for the real unit.

### Also fixed in this release
- Chooser: button text is centred in every button, the explanation line no longer runs under the RAM button, and the **Quit** button now works (it had no action behind it).
- Oversized firmware is described as **Extra Large (XL)** firmware throughout the Quick Start and README.

### Carried over from earlier builds
Virtual unit (`unit.flash`) with Power on / Flash OS / Developer direct load, byte-exact install chain, the flash `F0` data-word fix, the cheat sheet overlay, readable fonts.

### Notes
- No firmware is included; supply your own.
- The macOS builds are ad-hoc signed, not notarised: right-click, **Open** the first time.
- Not covered: the boot-block recovery updater (`MPC2500.SOS`) from the chooser, and power loss in the middle of an install.
